# Little Film Booth

A tiny browser camera app, take a picture and it's framed up like a brown instant-film print.

- Pure HTML/CSS/JS, no build step, no dependencies
- Camera access stays entirely in your browser ( no upload no backend )
- Works on desktop and mobile (uses the front camera by default)

## Run it

Just open `index.html` in a browser, or host it with GitHub Pages / Netlify / any static host.
